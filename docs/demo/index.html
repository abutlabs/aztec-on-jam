The demo

Private payments in Aztec's model — notes, nullifiers, proofs made on the sender's device — running live on a six-validator JAM testnet. Nothing in the recording is mocked.

What the chain shows

MoveAnyone can read on chainNot on chain
Pay publiclypayer, payee, amount
Shieldthe account, the amount, a note commitmentwho will own the note
Send privatelytwo nullifiers, two commitments, two sealed notessender, recipient, amount
Unshieldthe amount and the receiving accountwhich notes paid for it

The recording's last minute reads the same chain three ways: with no key (private transfers are ciphertext), with the sender's keys (her spends and change appear), and with a viewing key (incoming notes open; spending stays invisible). Self-custody with selective disclosure — Aztec's model, enforced by JAM.
