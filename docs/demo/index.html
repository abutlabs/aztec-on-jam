The demo

Private payments in Aztec's model — notes, nullifiers, proofs made on the sender's device — running live on a six-validator JAM testnet. Nothing in the recording is mocked.

One payment, end to end

  1. The sender proves, on their own machine.

    A browser tab builds a zero-knowledge proof of the transfer with Aztec's proving stack (Noir and Barretenberg): about one second.

  2. JAM validators verify it.

    The proof travels in a work-package; the service verifies it on-chain for 49M gas with the proposed curve calls, 147M without — 1 to 3% of a package.

  3. The chain writes only ciphertext.

    New note commitments, spent-note nullifiers, and two sealed notes. No sender, no receiver, no amount.

  4. The receiver finds the money with their key.

    Their browser scans the sealed notes; the one that opens is theirs. Nobody told them; nobody else can tell.

The recording's last minute reads the same chain three ways: with no key (private transfers are ciphertext), with the sender's keys (her spends and change appear), and with a viewing key (incoming notes open; spending stays invisible). Self-custody with selective disclosure — Aztec's model, enforced by JAM.

Real, and reduced

Real

  • The proofs: made by the sender, verified on-chain; any tampering is refused
  • The state: written only from the chain's own roots; replays change nothing
  • The keys: self-custodial, never leave the browser
  • The network: six validators, two independent JAM clients, GRANDPA finality

Reduced

  • The circuit is ours, written to Aztec's shapes — not Aztec's kernel circuits. Replacing it is the current work
  • Dev-chain money: a faucet, an unsigned public ledger, published dev keys
  • Notes found by trial decryption, not Aztec's tagging; one proof per package, no folding

The same service blob runs on PolkaJam (Parity's client, v0.8.0) and on lasair (ours) with identical gas — the measurements, client comparisons and scripts are in docs/DEMO.md.

Run it

scripts/bootstrap.sh     # pinned toolchain and builds
nets/demo.sh up          # six validators, services deployed, wallet on :19710
nets/demo.sh check       # a shield, a private send, an unshield: 37 assertions
nets/demo.sh down

Needs Rust, Python 3.11+, Node 20+ and Chrome. Ten minutes, for a JAM implementer.
