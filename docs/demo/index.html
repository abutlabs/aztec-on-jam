The demo

Aztec's own software, as released — wallet, node and prover — with JAM in Ethereum's place, on six JAM validators on one laptop. A private token transfer, proved in the browser, verified by Aztec's node, settled and finalized by JAM; then Aztec's proof of the whole epoch, verified by JAM too.

Beside the wallet, who is doing what, live: the browser proving, Aztec's node checking the proof and building a block, the sidecar handing the checkpoint to JAM, JAM's validators verifying and finalizing it, Aztec's prover proving the epoch. Waits are sped up, never cut.
