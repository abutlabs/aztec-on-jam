Run it

Aztec's sequencer and prover — the same released software Aztec's operator docs describe — running against a six-validator JAM testnet on one machine.

Get the code

git clone https://github.com/abutlabs/aztec-on-jam
cd aztec-on-jam
scripts/bootstrap.sh      # pinned toolchain; needs Rust, Python 3.11+, Node 22+ and Chrome

Start everything

(cd wallet && npm install && npm run build)          # the wallet, once
DEVNET_NET=jb-lasair6 tools/aztec-local/on-jam.sh    # everything, in order

One command brings up six JAM validators with the settlement service, the JAM sidecar, Aztec's sequencer node, Aztec's prover and the wallet. It prints each step as it finishes and the wallet's address at the end. Leave DEVNET_NET out to use PolkaJam's testnet instead of lasair; PROVER=0 skips the prover. Docker runs the public-execution agent: Aztec publishes that prover for Linux only. Stop with Ctrl-C, or tools/aztec-local/on-jam.sh down from another terminal.

What runs

ProcessAztec's flagsPortJob
Sequencer node--node --sequencer8080verifies every transaction's proof, builds blocks, sends them for settlement
Prover broker--prover-broker8084queues proving jobs
Prover node--prover-node8083finds unproven epochs, splits them into proving jobs, submits the epoch proof
Prover agent--prover-agent8086proves the jobs: the rollup circuits, natively
Public-execution agent--prover-agentDockerproves public execution (the AVM), in Aztec's own image
JAM sidecar(ours)8545stands in for Ethereum; relays blocks and proofs to JAM

Proving on a laptop

Apple M1 Pro, 10 cores, 16 GB, one agent. Real proofs, each verified.

ProofTime
An empty block1 s
A block with one transaction4 s
One private transaction, in the rollup18 s
Public execution (the AVM), one transaction5–51 s
A transaction with public calls, in the rollup140–330 s
A checkpoint of blocks31–60 s
The epoch's final proof60–171 s
JAM checks that proof and advances the proven tip70.7M gas, 0.55 s

Peak memory: 3 GB for the rollup proofs; about 6.4 GB for a transaction with public calls, so the public-execution agent runs one job at a time in Docker's 8 GB. A test network's epochs are small; Aztec's 128 GB guidance is for mainnet traffic.

Check it works

node tools/aztec-local/send-tx.mjs     # a private transfer from a fresh account; asserts balances
node wallet/e2e.mjs                    # Alice and Bob in two browsers

Logs: out/aztec-devnet/ — node, prover, broker, sidecar.
