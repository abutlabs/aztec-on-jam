Run it

Aztec's sequencer and prover — the same released software Aztec's operator docs describe — running against a six-validator JAM testnet on one machine.

Get the code

git clone https://github.com/abutlabs/jam-privacy-service
cd jam-privacy-service
scripts/bootstrap.sh      # pinned toolchain; needs Rust, Python 3.11+, Node 22+ and Chrome

Start everything

DEVNET_NET=jb-lasair6 PROOF_SUBMISSION_EPOCHS=10000 PROVER=1 \
  tools/aztec-local/on-jam.sh --node --sequencer

One command brings up six JAM validators with the settlement service, the JAM sidecar, Aztec's sequencer node, and Aztec's prover. Leave DEVNET_NET out to use PolkaJam's testnet instead of lasair.

cd wallet && npm install && npm run build && node serve.mjs    # the wallet, on :19720

What runs

Proving on a laptop

Apple M1 Pro, 10 cores, 16 GB, one agent. Real proofs, each verified.

ProofTime
An empty block1 s
A block with one transaction4 s
One private transaction, in the rollup18 s
A checkpoint of blocks31–42 s
The epoch's final proof60–79 s

Peak memory: 3 GB. A test network's epochs are small; Aztec's 128 GB guidance is for mainnet traffic.

Check it works

node tools/aztec-local/send-tx.mjs     # a private transfer from a fresh account; asserts balances
node wallet/e2e.mjs                    # Alice and Bob in two browsers
