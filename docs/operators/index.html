Running Aztec's operators on JAM

The same released software Aztec's operator docs describe — the sequencer node, the prover broker, the prover node and agents — pointed at a six-validator JAM testnet instead of Ethereum. One script starts everything; this page says what runs, how the mainnet settings map, and how to see it working.

One command

DEVNET_NET=jb-lasair6 PROOF_SUBMISSION_EPOCHS=10000 PROVER=1 \
  tools/aztec-local/on-jam.sh --node --sequencer

That brings up, in order: six lasair validators with the settlement service deployed; the jam-l1 facade (the node's "Ethereum"); Aztec's node with the sequencer; the prover broker; the prover node with one agent. Needs Node 22+, the pinned toolchain (scripts/bootstrap.sh) and lasair built. Logs land in out/aztec-devnet/: node.log, broker.log, prover.log, jam-l1.log, devnet.log.

The processes, as Aztec's docs lay them out

ProcessAztec's role flagsPort hereWhat it does
Sequencer node--node --sequencer8080 (admin 8880)verifies every client proof (real-proof mode is our default), builds L2 blocks, proposes checkpoints to "L1"
Prover broker--prover-broker8084queues proving jobs; must be a process of its own (aztec start refuses it beside --node)
Prover node + agent--prover-node --prover-agent8083 (admin 8885)watches the chain for unproven epochs, cuts jobs; the agent proves them with native bb and noir-execute
jam-l1 facade(ours)8545answers all of the above as Ethereum would; relays checkpoints and proofs as JAM work packages

Startup order, as Aztec's docs say: broker before agents; every role checks the rollup's genesis and stands by until it matches, so each gets the genesis settings.

Seeing it work

  • The chain: node_getNodeInfo on :8080 answers with chain 31337; the facade's jam-l1.log shows every checkpoint accepted by the settlement service.
  • The sequencer verifies proofs: grep "verify Chonk proof" out/aztec-devnet/node.log — one per transaction; a tampered proof is refused in ~141 ms.
  • The broker has work: grep "Proving job complete" out/aztec-devnet/broker.log.
  • The agent proves: grep "Generated proof" out/aztec-devnet/prover.log — circuit, size, duration.
  • A transfer end to end: node tools/aztec-local/send-tx.mjs (proves client-side, sponsored fee, asserts balances) or the wallet e2e, node wallet/e2e.mjs.
