Two checks, both by JAM

The epoch proof

Aztec's prover folds every transaction in an epoch into one proof; JAM verifies it. This is Aztec's own design, and it works with or without the JIP.

Every transaction's proof

JAM's validators re-check each transaction themselves — the strongest guarantee JAM offers. It needs the JIP: one proof costs 11.4B gas without it, more than two work packages; 3.5B with it.

A small work package holds 1B gas; a full one 5B. Gas is the protocol's: the same on every JAM client.
