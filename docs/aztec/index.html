Who checks the client proofs: two paths

A. Aztec's own design

The sequencer checks each client proof when it arrives, and the rollup circuits fold them all into one epoch proof. JAM checks that epoch proof, the blobs and the signatures. Everything above the seam stays Aztec's code, and no curve call is required. The calls make an epoch's settlement 5.6× cheaper and a checkpoint's blob check 2.9×.

Needs a real prover for epochs. That is the hardware question.

B. JAM checks each client proof

Refine runs Aztec's own verifier on every transaction's proof, so JAM's validators re-execute the check themselves. Call 105 is required: without it one proof costs 11.36B gas, more than two full packages. Accumulate would also have to keep Aztec's trees.

Built as far as one proof, finalized on lasair. A research path, not needed for path A.
